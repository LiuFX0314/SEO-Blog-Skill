# B2B SEO Blog Skill (OpenClaw)

A dynamic SEO blog generation system designed for B2B websites.

## Features

- Keyword-based SEO blog generation
- Dynamic strategy detection
- SERP simulation
- SEO optimization (meta, structure, keywords)
- Conversion-focused writing (CTA, internal linking)

## Structure

- SKILL.md → Skill logic
- tools.json → Tool definition
- handlers/ → Execution logic
